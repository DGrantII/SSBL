# SSBL

This project, a web application for an e-sports league, represents my progress and growth as I learned software development. I worked on this project throughout my learning journey, and it reflects the skills and knowledge I acquired along the way.

I am aware that the code may not be the prettiest or most optimized, but it stands as a testament to my dedication and willingness to improve. Every feature and function was an opportunity to learn something new.

## Features

Front-End: Vanilla HTML, JavaScript, and CSS

Back-End: Node.js, Express.js, Mongoose, MongoDB (with data stored on a local server, not visible)
